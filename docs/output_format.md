# 輸出格式（v1.6）

`ebook2md convert` 寫出的 md，以及 `ebook2md slice` 寫出的章節 JSON。章節切分只依這份文件讀 md；改格式時先改這份文件與測試。

## 1. md 開頭

每份 md 以這個區塊開頭，四行之間各空一行，最後一行是 `---`：

```markdown
# 書名：{書名}

# 作者：{作者}

# 轉換日期：{YYYY-MM-DD}

# 轉換器：ebook2md {版本} ({commit})

---
```

| 欄位 | EPUB | PDF |
|---|---|---|
| 書名 | metadata 的 `dc:title`；沒有就用檔名（不含副檔名） | 檔名（不含副檔名） |
| 作者 | metadata 的第一個 `dc:creator`；沒有就是 `Unknown Author` | 呼叫端給的作者；命令列沒有這個參數，是空字串 |
| 轉換日期 | 轉檔當天 | 同左 |
| 轉換器 | 見下 | 同左 |

**轉換器**：`ebook2md 1.6.0 (abc1234)`。括號裡是轉檔時套件所在的 git commit；套件有未 commit 的修改時加 `+dirty`（例：`(abc1234+dirty)`）；不是從 git checkout 執行（例如一般 `pip install`）時沒有括號。v1.6 以前轉出的 md 沒有這一行。

同一份程式、同樣的相依套件版本，同一本書轉兩次，除了轉換日期以外逐位元相同。

## 2. `---` 與 `* * *`

- 單獨一行的 `---` 只代表文件分界：EPUB 是每個 spine 檔之間；PDF 是每個最上層書籤標題之前。開頭區塊之後也有一個。
- EPUB 內文的 `<hr>` 輸出成 `* * *`，不會是 `---`。
- 章節切分以 `---` 為第一層分界，所以 `---` 不能出現在其他用途。

## 3. 標題

- EPUB：HTML 的 `h1`～`h6` 轉成 `#`～`######`。目錄（TOC）有、內文沒有的標題，依 TOC 層級插入（最深 `######`）；TOC 錨點落在句子中間時不插。整頁只有圖片的檔，只輸出它的 TOC 標題。
- PDF 有書籤：書籤標題取代頁面上同一行字；頁面上找不到時插在該頁開頭。最上層書籤是 `#`，往下一層加一個 `#`（最多 6 個）。第一層書籤少於 3 個、底下還有其他層時（第一層通常只是書名），由第二層當最上層。書籤標題內的換行併成一行。
- PDF 沒有書籤：橫排頁上字級至少是正文 1.25 倍、30 字以內的行，輸出成 `## `；直排頁不判斷標題。

## 4. 段落與其他元素

- 檔案以 UTF-8 寫出，換行字元依作業系統（Windows 上是 CRLF）。
- 段落之間空一行；連續三個以上換行壓成兩個。
- PDF：排版斷行合併成一行（中文之間不加空格，英文加空格、行尾連字號接回）；跨頁的段落接成一段；頁首、頁尾、頁碼刪除。
- EPUB 圖片：有替代文字輸出 `[圖片說明: {替代文字}]`，沒有輸出 `[圖片]`；標題裡的裝飾小圖不輸出。PDF 的圖片不輸出任何標記。
- 連結：外部連結（`http`、`https`、`mailto`）保留成 Markdown 連結；書內連結只留文字。
- 底線不跳脫（`_` 原樣輸出）；表格與程式碼區塊照 markdownify 的輸出。

## 5. 章節 JSON（`ebook2md slice`）

```json
{
  "source": "書檔名.epub",
  "converter": "ebook2md 1.6.0",
  "report": { "self_check": true, "back_matter": [ { "title": "參考書目", "char_count": 5230 } ], "...": "..." },
  "chapters": [
    { "chapter_num": 1, "title": "第一章", "char_count": 12034, "content": "第一章\n……" },
    { "chapter_num": 2, "title": "第二章（1/2）", "char_count": 39876, "content": "……", "split": "paragraph" }
  ]
}
```

- `chapters[].content` 是原文的連續行（EPUB 是 HTML 文字依標籤切開的行，md 是原本的行），只在行與行之間切，不改字。`char_count` 等於 `content` 的長度。
- 超過 40,000 字的章再拆，`split` 記拆法：`toc_sub`（TOC 小節）、`heading`（標題）、`paragraph`（段落，標題加「（k/n）」）。單一段落就超過上限時不拆，列在 `report.still_oversize`。
- 書末附屬（注釋、書目、索引等，標題整個由這類詞組成、而且在全書後半）與章末注釋不放進 `chapters`，只把標題與字數列在 `report.back_matter`；章末注釋的 `kind` 是 `chapter_notes`。
- 不到 200 字的片段併進相鄰的章；但很短的書目仍列書末附屬，書目前的短正文併回前一章。
- `report.self_check` 為 `false` 時（章節與書末附屬拼不回原文），命令列回報失敗、不寫檔。
- 從 md 切時，開頭區塊（以 `# 書名：`、`# 作者：`、`# 轉換日期：` 或 `# 轉換器：` 開頭的那一段）不算章節，只有圖片標記的段落也略過。
